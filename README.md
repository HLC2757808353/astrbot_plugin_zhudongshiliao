# 主动私聊插件 v0.8.2

为AstrBot提供跨会话消息转发、AI主动回复和沉浸式对话延续功能。主要适配QQ（aiocqhttp）。

## 核心特性

- **同一会话**：所有功能（主动回复、对话延续、跨会话转发）都在已有会话中进行，不创建任何临时会话
- **双向上下文**：跨会话转发时，来源会话和目标会话的AI都知道完整的前因后果
- **记忆一致性**：两个不同会话的AI对同一件事有相同的认知

## 功能列表

### 消息工具（AI自主调用）

| 工具 | 说明 |
|------|------|
| `private_message` | 向指定用户发送私聊消息 |
| `group_message` | 向指定群发送消息 |
| `message_to_admin` | 向管理员发送消息 |
| `sue_to_admin` | 向管理员告状（被动触发，AI根据人格决定是否使用） |
| `get_admin_info` | 获取管理员配置信息 |

### 主动回复

AI在设定的时间窗口内，如果管理员长时间没有说话，会主动发消息。使用同一个会话，AI有完整的对话记忆。

### 沉浸式对话延续

当AI的回复包含提问或情感表达时，如果用户没有回应，AI会在超时后自动追问。最多延续3轮，AI可以选择保持沉默。

### 自定义报错

当AI出现错误时，用自定义消息替换原始错误信息，支持 `{error_message}` 和 `{error_code}` 变量替换。

## 跨会话上下文机制

这是本插件最重要的设计。以群A → 私聊用户B为例：

**目标会话（用户B的私聊）收到：**
```
[跨会话通知] 用户A在群聊「群X」让你给当前用户发了消息：「你好呀，最近怎么样？」。
以下是来源对话的最近内容，帮助你理解前因后果：
用户: 张三最近没来群里，有点担心他
AI: 是啊，他上次说工作很忙
用户: 你帮他发个消息问候一下吧
AI: 好的，我给张三发个消息
```

**来源会话（群A）收到确认：**
```
[你已成功向私聊「用户张三」发送了消息：「你好呀，最近怎么样？」。如果对方回复，你会知道。]
```

这样两边的AI都知道完整的前因后果，而不是只知道"发了一句话"。

## 配置项

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 管理员ID | 空 | 管理员QQ号，用于告状和主动回复 |
| 启用告状 | 是 | 开启/关闭告状功能 |
| 自定义报错消息 | 请有人告诉引灯续昼我的AI出现了问题 | 错误时的回复消息 |
| 启用自定义报错 | 是 | 开启/关闭自定义报错 |
| 主动回复开关 | 否 | 开启后AI会主动联系管理员 |
| 主动回复起始时间 | 9 | 主动回复时间窗口（小时） |
| 主动回复结束时间 | 23 | 主动回复时间窗口（小时） |
| 主动回复最小间隔 | 1800秒 | 两次主动回复的最小间隔 |
| 主动回复最大间隔 | 7200秒 | 两次主动回复的最大间隔 |
| 时区偏移 | 8 | UTC偏移量，中国为8 |
| 沉浸式对话延续 | 否 | 开启后AI会在用户不回复时追问 |
| 对话延续超时 | 300秒 | 等待用户回复的超时时间 |
| 对话延续最大轮次 | 3 | 最多连续追问次数 |
| 历史消息最大数量 | 50 | 每个会话保存的最大消息数，防止内存增长 |

## 安装

1. 将插件放到 `AstrBot/data/plugins/` 目录
2. 重启AstrBot，插件自动加载

## 使用说明

- 插件作为工具供大模型调用，AI根据对话内容自主决定何时使用
- 首次私聊会自动绑定管理员UMO，无需手动配置
- 主动回复使用同一个会话，AI有完整记忆
- 跨会话转发时，两边的AI都会收到上下文通知

## 注意事项

- 私聊功能需要对方和AI已经是好友
- 历史消息数量限制（默认50条）会自然淘汰旧消息，不是永久记忆
- 主动回复只在设定的时间窗口内触发
- 对话延续每轮AI都可以选择保持沉默
